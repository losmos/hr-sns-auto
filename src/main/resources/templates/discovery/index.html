브라우저 보강:

공개 author/profile 정보만 읽으며 로그인·challenge는 자동 우회하지 않는다.

로그인은 열린 Chromium에서 직접 수행한다. 앱은 Instagram ID/PW를 받지 않으며 session profile은 git에 포함하지 않는다.

사용하려면 INSTAGRAM_BROWSER_AUTOMATION_ENABLED=true로 실행한다. API Discovery는 이 설정과 무관하게 동작한다.
